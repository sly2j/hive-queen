=== hive  --help
usage: hive [-h] [--version] [--profile NAME]
            {up,down,restart,status,attach,list,spawn,stop,reconcile,launchers,discover,dirs,roots,inspect-launcher,init,install-service,uninstall-service}
            ...

Run N instances of each agent kind in tmux panes.

positional arguments:
  {up,down,restart,status,attach,list,spawn,stop,reconcile,launchers,discover,dirs,roots,inspect-launcher,init,install-service,uninstall-service}
    up                  start the session, or reconcile it with the config if running
    down                stop the session (and the hive tmux server if empty)
    restart             restart via systemd if the unit is active, else down + up
    status              show windows and panes (exit 1 if not running)
    attach              attach to the session
    list                show config and running state, unmanaged panes, drift
    spawn               add workers (edits config, then reconciles)
    stop                remove workers (edits config, then reconciles)
    reconcile           make the running session match the config
    launchers           list the launcher registry and discover records
    discover            run [queen] discover and print its output
    dirs                read-only: list directories under search_roots
    roots               show search_roots, or add/remove one (edits config)
    inspect-launcher    read-only: show a launcher's CLAUDE_CONFIG_DIR evidence (files under
                        inspect_roots only)
    init                write an example config if none exists
    install-service     write the systemd user unit
    uninstall-service   disable and remove the systemd user unit

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --profile NAME        use the named profile <config dir>/hive/profiles/NAME (own config, lock,
                        queen dir, tmux socket hive-NAME, unit hive-NAME.service); default:
                        $HIVE_PROFILE, else the default profile

exit codes:
  0  ok
  1  runtime error, or the session is not running
  2  usage or config error
  3  untrusted or refused (spawn without --trust, dirs/roots refusals)

2 instead of guessing.

=== hive spawn --help
usage: hive spawn [-h] [-n N] [--type TYPE] [--command CMD] [--arg ARG] [--config-dir PATH]
                  [--launcher NAME] [--env KEY=VALUE] [--trust]
                  TARGET

Add workers: raise the count of an existing agent type, or add a new type for a directory. Exit 3
if the directory is untrusted (rerun with --trust after the user confirms).

positional arguments:
  TARGET                agent type, or a directory (absolute, ~/..., or a name under search_roots)

options:
  -h, --help            show this help message and exit
  -n N                  number of workers to add (default 1)
  --type TYPE           agent type name for a new entry (default: directory name, plus -<launcher>
                        when a launcher is chosen; letters, digits, '.', '_' and '-' only)
  --command CMD         command template; must contain {name} and --remote-control
  --arg ARG             flag added to the command of a new type (repeatable); use --arg=--fable
                        for values starting with '-'
  --config-dir PATH     Claude config dir the command uses; only locates the trust file
  --launcher NAME, --sandbox NAME
                        take command and config_dir from launcher NAME (registry, then [queen]
                        discover); --sandbox is an alias
  --env KEY=VALUE       env for a new type, exported after [env] (repeatable)
  --trust               record Claude Code workspace trust for the directory (only after the user
                        agreed)
=== hive stop --help
usage: hive stop [-h] [-n N] [--index N] TARGET [TARGET ...]

Remove workers: N of a type, highest index first, the instances --index names, or the instances
named <type>-<machine>-<N>. A TARGET that is a type is a type.

positional arguments:
  TARGET      agent type, or one or more instance names

options:
  -h, --help  show this help message and exit
  -n N        number of workers to remove (default 1)
  --index N   remove instance N of TYPE (repeatable)
